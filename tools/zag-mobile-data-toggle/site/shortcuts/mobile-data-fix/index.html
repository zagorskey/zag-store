Zag Mobile Data Toggle

An Apple Shortcut that lets Zag Store install apps while you’re using 4G or 5G.

Why Zag Store needs it

Over Mobile Data, iOS blocks the connection Zag Store uses to install apps. Downloads still work, but the install can’t finish.

Zag Mobile Data Toggle temporarily turns Mobile Data off during installation and allows it to be restored afterwards.

What it does

  • off: turns Mobile Data off.
  • on: turns Mobile Data back on.
  • status: tells Zag Store it’s installed. It changes nothing.
  • Anything else is refused without changing your settings.

It runs in Apple’s Shortcuts app, which opens briefly each time. It only runs when you tap in Zag Store, and you can open it in Shortcuts to see every step.

Set it up

  1. If you already have a shortcut called Zag Mobile Data Toggle, delete it first.
  2. Tap Get Shortcut below. If Safari asks, tap Download, then open the file from Downloads.
  3. In Shortcuts, tap Add Shortcut. Keep the name Zag Mobile Data Toggle.
  4. Return to Zag Store: Settings → Installation → Apply Mobile Data Fix → Verify Shortcut.
