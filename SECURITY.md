# Security Policy

Zag Store handles sensitive signing assets and interacts with iOS installation services.

## Reporting a vulnerability

Please **do not** report exploitable vulnerabilities or include sensitive signing materials in public issues.

If GitHub private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** option. Otherwise, contact the maintainers through a verified private contact channel published at [zagstore.app](https://zagstore.app).

Describe the affected version, impact, and reproducible steps. Do not transmit real private keys, certificate passwords, or provisioning profiles.

## Areas of interest

Certificate and key handling, signing, installation transport, update integrity, repository parsing, and server-side delivery.

Zag Store is in beta. Security support and response-time commitments have not yet been formally established.
